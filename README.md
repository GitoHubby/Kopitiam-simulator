# Malaysian Kopitiam Simulator

A cozy browser game set in a 1990s-style Malaysian kopitiam. The shop runs itself: customers sit, queue at the food stalls (Gei Si Hor Fun, Wan Tan Mee, Chicken Rice, Char Kuey Teow and more) and eat. **You run the drinks counter.** Your staff take the orders at the tables; you mix each Kopi, Teh Tarik or Milo Ais exactly right and send it out before the uncles start waving.

**Play:** https://gitohubby.github.io/kopitiam-simulator/

- 5 shifts, from a quiet morning to a busy weekend, with rain and hot-weather effects
- Drink customisation: O / C / pekat, kosong to extra manis, panas or ais, ice levels, tarik
- Regulars who expect you to remember "the usual", and tourists who order in English
- Upgrades, star ratings and a semi-3D view you can rotate

Single file (`index.html`), no build step. It loads Three.js from cdnjs, so it needs an internet connection. Progress is saved in your browser.
